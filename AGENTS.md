# Agent instructions

This repo is the design work for a fold-flat, tool-free tenting case for Tom's Urchin split keyboard. Start by reading `HANDOFF.md`, which holds the requirements, the decisions so far and their reasons, the current concept and the open questions.

- Tom places all orders and handles anything external. Don't upload designs, request quotes or order anything on his behalf; prepare the files and tell him what to do.
- The design has been through several rounds of pushback, so if something in `HANDOFF.md` looks wrong, raise it rather than working around it quietly.
- Keep `viewer/index.html` working when changing shared data. It embeds the board data from `data/urchin-right-half.json`, which is generated by `tools/extract_pcb.py` from the Urchin KiCad file.
- Check visual changes by rendering screenshots (see the viewer section of `HANDOFF.md`) rather than assuming they look right.
- Markdown style: sentence-case headings; keep bold, italics and emoji to a minimum.
